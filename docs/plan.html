      Rules that keep you moving+
      • Start week 1 today — the single win the summer never gave you.
      • Ugly-but-working beats clean-but-late. You can refactor a thing that runs.
      • If docker-java fights you, switch to the docker CLI fallback fast — don't lose 3 days to thin docs.
      • Never write Terraform and Ansible in the same week — two mental models at once is where people quit.
      • When Ansible fails, do it by hand over SSH first, then translate to a playbook.
      • Set an AWS billing alarm at $5 before creating anything. terraform destroy when away.
      Reaching week 8 with v1 solid is already a win — and a real portfolio piece. Everything after is upside.
